# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2025-12-09

### Added

- Initial release of Theme Switcher.
- Three theme modes: `light`, `dark`, `auto` (follows OS preference).
- `localStorage` persistence of the selected theme.
- Live system theme change detection for `auto` mode.
- Automatic `html.dark` class management.
- Active/inactive button state handling.
- Responsive styles for mobile, tablet, and desktop.
- Accessibility support: ARIA labels, keyboard navigation, focus states, `prefers-reduced-motion`.
- Zero dependencies, framework-agnostic design.
